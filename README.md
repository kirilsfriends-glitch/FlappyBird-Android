# Flappy Bird - Android Game

Простая игра Flappy Bird для Android устройств.

## Описание

Это классическая игра Flappy Bird, реализованная на Java для Android. Помогите птичке пролететь между трубами и набрать как можно больше очков!

## Как играть

- Коснитесь экрана, чтобы птичка прыгала
- Избегайте столкновения с трубами
- Каждая успешно преодоленная труба = 1 очко
- При столкновении игра заканчивается
- Коснитесь экрана еще раз, чтобы начать новую игру

## Компиляция и установка

### Требования
- Android Studio
- Android SDK 21+
- Java JDK

### Шаги

1. Откройте проект в Android Studio
2. Выполните `Build > Build APK`
3. Установите APK на Android устройство или эмулятор
